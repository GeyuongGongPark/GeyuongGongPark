## About Me

🔍 리걸테크 스타트업 **아미쿠스렉스(Amicus Lex)**에서 CLM 솔루션 **로폼(Lawform)**의 QA 팀을 리딩하고 있습니다.

🎮 넥슨(Nexon)에서 대규모 디바이스팜을 운영한 경험을 시작으로, 게임 산업과 리걸테크를 넘나들며 QA 조직과 프로세스를 "0에서 1로" 만들어온 10년 차 QA 엔지니어입니다.

🛠 Playwright · Grafana k6 기반 비기능 테스트 확장, Jira/Confluence 기반 QA 프로세스 구축을 주도합니다.

🤖 Anthropic Claude API를 활용한 멀티 에이전트 시스템(Avengers Agent System)을 직접 설계·운영하며 QA에 AI를 접목하는 실험을 이어가고 있습니다.

💬 QA 문화, Shift Left, 품질 지표(Metrics)에 관심이 많습니다. 편하게 이슈나 DM 남겨주세요!
